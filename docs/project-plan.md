# 복지문턱 프로젝트 계획서 — 초안

## 목표
복지서비스 신청 과정의 복잡도를 항목별로 설명하고 지원 조건·내용·신청 절차를 쉬운 문장으로 전달한다.

## 데이터와 방법
- 중앙·지자체 복지서비스 API에서 서비스 식별자, 지원대상, 선정기준, 지원내용, 신청방법을 수집한다.
- 실제 API 제공기관·엔드포인트·이용조건은 확인 후 출처에 기재한다.
- 조건·기관·서류를 추출하고 근거 문장을 보존한다. 확인되지 않은 정보는 결측으로 남긴다.
- 설명 가능한 가중합으로 문턱 점수를 산출한다. 가중치와 환산 기준은 팀 검토 후 확정한다.
- 규칙 기반 추출과 언어 모델 추출을 동일한 수작업 정답표로 비교한다.
- 쉬운 설명에서 원문 숫자·단위·조건의 보존 여부를 검사한다.

## 검증 계획
50~100개 서비스에 대해 팀이 조건·서류·신청방식을 직접 판정한다. 항목별 정확도와 서류 추출의 precision/recall, 결측률, 쉬운 설명의 숫자 보존율을 보고한다. 점수 분포와 가중치 변경에 따른 순위 변화도 확인한다. 실제 결과를 얻기 전에는 성능 수치를 기재하지 않는다.
