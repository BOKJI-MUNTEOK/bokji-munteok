# 90초 시연 구성안

현재 UI 프로토타입을 녹화할 때 사용하는 구성이다. 가상 데이터임을 영상과 설명란에 명시한다.

| 시간 | 화면 | 설명 |
| --- | --- | --- |
| 0~15초 | 메인 화면 | 복지문턱은 복지 신청 과정의 어려움을 비교하고 준비를 돕는 프로젝트입니다. 현재 화면은 가상 데이터 6개를 사용하는 UI 데모입니다. |
| 15~30초 | 검색·필터 | 검색어와 신청방법으로 서비스를 좁히고 관심 서비스를 저장합니다. |
| 30~50초 | 점수 상세 | 온라인 신청, 방문 여부, 조건과 서류 수 등으로 점수를 계산합니다. 점수의 이유를 항목별로 확인할 수 있습니다. |
| 50~65초 | 쉬운 설명 | 대상·조건·지원내용·신청순서를 나눠 보여줍니다. 현재는 미리 작성한 예시이며 AI 연결은 예정입니다. |
| 65~80초 | 준비 체크리스트 | 준비사항을 확인하고 서류 정보가 없으면 미확인으로 안내합니다. |
| 80~90초 | 메인 화면 | 실제 데이터를 연결하고 추출 정확도와 숫자 보존 여부를 검증할 계획입니다. |
