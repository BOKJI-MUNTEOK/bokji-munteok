# 시연 동영상

- YouTube: https://youtu.be/0btVZg8UhJk
- 길이: 2분 0초 (1920×1080, 60fps, 소리 없이 단계별 자막)
- 녹화: 2026-11-22, 운영 서비스(https://bokji-munteok.streamlit.app)를 자동 조작하며 화면을 녹화
- 입력값: 시연용 값이며 연락처는 가짜 번호, 주소는 구로구청 도로명주소에 동·호수를 붙인 것

## 구성

| 시각 | 단계 | 화면에서 보이는 것 |
| --- | --- | --- |
| 0:00 | AI 상담 | 내 복지 찾기 → AI와 대화로 찾기, "서울 구로구에 사는 68살이고 혼자 살아요. 병원비가 걱정이에요." 입력 |
| 0:20 | 추천 결과 | AI가 먼저 볼 복지 3개를 고르고, 신청서를 바로 쓸 수 있는 복지와 받는 방법을 안내할 복지로 나눔 |
| 0:39 | 쉬운 설명·문턱 점수 | 노후긴급자금 대부사업의 쉬운 설명(누가·무엇을·어떻게), 6개 기준표로 계산한 문턱 점수 |
| 0:57 | 신청서 열기 | 서류 작성·인쇄 → 국민연금 노후긴급자금 대부 신청서(.hwp) 열기, 이름·연락처·생년월일 입력 |
