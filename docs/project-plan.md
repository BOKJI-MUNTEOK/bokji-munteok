## 문턱 점수 항목 (안)

| 항목 | 점수 |
| --- | --- |
| 온라인으로 신청할 수 없음 | +3 |
| 꼭 방문해야 함 | +2 |
| 거치는 기관(신청·조사·결정) | 기관 하나마다 +1 |
| 받을 조건 | 조건 하나마다 +1 |
| 내야 하는 서류 | 서류 하나마다 +0.5 (글에 없으면 비워 둠) |
| 안내문 난이도 | 0~3 |

가중치는 미국의 복지 신청 부담 평가 기준을 참고해 팀이 확정한다.

현재 구현은 기관 3단계·조건 6개·서류 8개·난이도 3점을 상한으로 두고 가중합을 환산합니다(`src/score.py`). 기본 가중치·상한은 팀 확정 전 안입니다. 상세를 받지 않은 서비스는 점수를 만들지 않습니다.
