# 정답표 작성 기준

사람이 원문을 직접 읽고 센 값(정답)과 규칙·AI가 뽑은 값을 비교해 정확도를 냅니다.

**원문에 적힌 것만 보고 판단합니다. 복지로·검색으로 따로 찾아보지 않습니다.** 규칙과 AI도 이 원문만 보고 뽑기 때문에, 바깥 정보를 섞으면 "글에서 얼마나 정확히 뽑았나"를 잴 수 없습니다. 원문에 온라인 이야기가 없으면 N입니다. 셋이 같은 기준으로 세야 비교가 의미 있으니 아래 기준을 따라 주세요. 애매하면 `메모` 칸에 적고 넘어갑니다.

## 내 파일

| 사람 | 파일 | 건수 |
| --- | --- | --- |
| 박다윗 | `gold_dawit.csv` | 17 (중앙 9, 지자체 8) |

**입력 화면으로 채우기(추천)**: `.venv/bin/python -m streamlit run eval/label_app.py` → 왼쪽에서 내 이름을 고르고, 원문을 읽으며 질문 5개에 답한 뒤 "저장하고 다음으로". 내 파일이 자동으로 채워집니다.

엑셀로 직접 채워도 됩니다. `원문` 칸을 읽고 앞쪽 칸을 채웁니다.

## 칸별 기준

| 칸 | 적는 값 | 기준 |
| --- | --- | --- |
| `online` | Y / N | 인터넷·정부24·복지로·홈페이지로 신청할 수 있으면 Y. 원문에 온라인 이야기가 없으면 N |
| `visit_required` | Y / N | 방문 말고 다른 방법(온라인·우편·전화·이메일·팩스)이 **하나도 없으면** Y. "방문 또는 우편"이면 N |
| `n_agencies` | 0~3 | 신청·조사·결정 세 단계 중 원문에 나온 단계 수. "구에서 서류 검토"는 조사, "선정·통보"는 결정 |
| `n_conditions` | 숫자 | 받을 자격 조건의 개수 (아래 세는 법) |
| `n_documents` | 숫자 또는 빈칸 | 원문에 적힌 서류 개수. 서류 이야기가 전혀 없으면 **빈칸**(0이 아님) |
| `documents(쉼표로)` | 글 | 서류 이름을 쉼표로. 예: `신청서, 통장사본` |

## 조건 세는 법

- 자격을 따지는 요건 하나가 1개입니다. 나이, 소득, 거주지, 가구 형태, 장애, 질환, 재산, 국적 등.
- 같은 요건을 다른 말로 반복하면 1개. (지원대상과 선정기준에 "65세 이상"이 두 번 나오면 1개)
- "A 또는 B"는 1개. (예: "독거노인 또는 심한장애 1인가구")
- 범위는 1개. "19~44세"는 나이 1개.
- 거주지와 거주 기간이 붙어 있으면 1개. "부산시에 6개월 이상 거주"는 1개.
- 소득 기준과 재산 기준은 따로 셉니다(2개).
- **조건이 아닌 것**: 지원 금액·한도, 지원 제외 항목, 신청 기간, 신청 방법, 우선순위("소득이 낮은 순으로 선정").

예시 — 주거약자 이사지원: "기초의료급여수급자 중 독거노인(만 65세 이상), 심한장애 1인가구 / 기준중위소득 40% 이내"
→ 기초의료급여수급자 1, 독거노인(만 65세 이상) 또는 심한장애 1인가구 1, 기준중위소득 40% 이내 1 = **3개**
